-----------------------------------------------------------------------------

			You need to be root
			Type: 		String
			Example: 	webserver

			You need to be root
			Type: 		String

			You need to be root
			Type: 		String
			Example: 	/var/htdocs
server.log.loglevel	0..9
server.no_keep-alive_ips List of IP-Adresses for clients not supporting keep-alive
			like JtG-Server. (comma separated list)

Website Settings
-----------------------------------------------------------------------------
ATTENTION only <website name> = WebsiteMain implemented now

<website name>.port
<website name>.directory
<website name>.override_directory
<website name>.hosted_directory
<website name>.special_locations	StringPairList

(directory, override_directory and hosted_directory are web folders: no
web folder may be, hold or lie in the configuration directory
(/var/tuxbox/config, which holds who may reach the box and the keys of the
services the box uses), /proc, /sys or /dev, after every link is followed,
and none may be or hold /tmp, where captures, uploads and archives wait; a
folder below /tmp may be one.
Such a folder is refused when the server reads this file: the server says
so in one line, uses the folder the box ships with instead, and serves
nothing from that setting where even the shipped one would be refused. A
relative folder, or one with a .. in it, is refused the same way.

Whatever the folders are, no file goes out of a descriptor whose file has
no name left, such as one opened through /proc/<pid>/fd/, nor one that
really lies in /proc, /sys or /dev, and none of the files that hold who may
reach the box goes out, by any name or link, while it is written or after
it was replaced. Out of the configuration directory a static answer sends
only the files the old pages' handlers name there (the channel lists), so
a folder link from a web folder into it reaches nothing; the API sends its
other files as before (GET /api/v1/storage/file, the documents of
/api/v1/config). None of its files goes out at all where the start found a
working file of a restore that ended with the program and could not keep
it.)

-----------------------------------------------------------------------------
module settings
-----------------------------------------------------------------------------
mod_auth.authenticate		true/false
mod_auth.no_auth_client=	IP-Adress of Client with no authentication

(mod_auth.username and mod_auth.password are gone: the account is kept
hashed in nhttpd-access.conf and checked through the REST layer's login. A box
that still has them in this file drops them at the start that carries them
into nhttpd-access.conf. A password these boxes shipped with is not carried:
the box makes up a first password in its place and shows it on the TV.)

mod_weblog.logfile	=/tmp/yhttpd.log
mod_weblog.log_format	=ELF|CLF|<empty>

(The log is written only directly in /tmp, the directory of the default file
above. A name anywhere else, a link, a file with a second name or of another
user, and a file that holds who may reach the box (nhttpd-access.conf,
nhttpd.conf and the files they are written through) leave the log off, and
the server says why once. A record, like every line server.log.loglevel
writes, leaves the values of a query out, shows a credential as [redacted]
and escapes control characters, so one request is one line.)

mod_cache.cache_directory=/tmp/.cache

mod_sendfile.mime_types=htm:text/html,html:text/html,xml:text/xml,txt:text/plain,jpg:image/jpeg,jpeg:image/jpeg,gif:image/gif,png:image/png,bmp:image/bmp,css:text/css
